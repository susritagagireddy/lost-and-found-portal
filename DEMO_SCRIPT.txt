[1:00 — ARCHITECTURE]
(show assets/architecture_diagram.png)
Let's walk through the architecture. When a user sends a message, it enters the START node and immediately goes through our Security Checkpoint node to scan for injections and scrub personal data. If it is a safe request, it goes to the orchestrator_agent which uses AgentTools to delegate tasks to the reporter_agent or the matcher_agent. These agents query a local JSON database via our Stdio MCP Server. Finally, if the matcher agent initiates a claim, the system pauses at the claim_verification Human-in-the-Loop node to request explicit confirmation before logging the transaction.
